Тесты EXIT

Веб-приложение с интерактивными психологическими тестами для самопознания и проверки знаний о компании EXIT/ROWANS.

Описание

Сайт представляет собой коллекцию из трёх тестов, которые помогают пользователям:
- Узнать, какой персонаж из вселенной EXIT им ближе по вайбу
- Проверить свои знания о компании ROWANS
- Определить свой тип личности

Все тесты имеют современный минималистичный дизайн, анимации и адаптивную вёрстку.

Особенности

- Современный дизайн — минималистичный стиль с чёрно-белой цветовой гаммой
- Адаптивность — корректное отображение на всех устройствах
- Плавные анимации — приятные эффекты при наведении и переходе между вопросами
- Мгновенный результат — автоматический подсчёт и вывод результата после последнего вопроса
- Детальная статистика — отображение баллов по каждому типу/категории

Тесты

1. Кто ты из EXIT?
- 10 вопросов о предпочтениях и характере
- 4 возможных результата: Главный герой, Барменша, Голос из рации, Шеран
- Каждый ответ влияет на итоговый процент совпадения с персонажем

2. Тест на ROWANS
- 10 вопросов о компании, играх и разработчиках
- Проверка знаний фактов о ROWANS и их проектах
- Результат показывает процент правильных ответов

3. Тип личности
- 10 вопросов о поведении и предпочтениях
- 5 типов личности: Стратег, Лидер, Гармонизатор, Творец, Исследователь
- Категоризация на основе поведенческих паттернов

Как пользоваться

1. На главном экране нажмите «Начать тест»
2. Выберите один из трёх доступных тестов
3. Отвечайте на вопросы, нажимая на вариант ответа — следующий вопрос появится автоматически
4. После последнего вопроса сразу показывается результат
5. Результат можно посмотреть, а затем пройти другой тест или вернуться к выбору

Особенности реализации

Система навигации
- Автоматический переход к следующему вопросу после выбора ответа
- Кнопка «Назад» для возврата к предыдущему вопросу
- Визуальный прогресс-бар и счётчик вопросов

Подсчёт результатов
- EXIT vibe — взвешенная система баллов, где каждый ответ увеличивает счёт определённого персонажа
- ROWANS — подсчёт количества правильных ответов
- Тип личности — распределение по категориям с учётом специальных вопросов для типа «Исследователь»

- Возможность поделиться результатом в соцсетях
- Добавление новых тестов
- Анимация появления результатов
- Режим тёмной темы
